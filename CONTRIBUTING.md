# Contributing to BlueRipple Passkey

Thank you for helping improve BlueRipple Passkey.

## Contribution workflow

1. Fork the repository.
2. Create a focused branch in your fork.
3. Add or update tests for behavioral changes.
4. Run `go test ./...` and `go vet ./...`.
5. Open a pull request against `main` and describe the security impact.

Direct pushes to `main` are not accepted. Pull requests require the automated
build and review by the repository owner, `@sqsergio1995`, before they can be
merged. Only the repository owner merges accepted changes.

By submitting a contribution, you agree that it may be distributed under the
project's MIT License.

## Security reports

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory reporting for this repository instead.
